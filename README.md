# VioRelay Android releases

This public repository is an artifact-only mirror for official VioRelay Android releases. It does not contain application source code. The VioRelay source repository remains private.

## Download

Signed APKs and their SHA-256 checksums will be attached to GitHub Releases after each release has been verified. No APK release has been published yet.

The primary download site is [viorelay-android.pages.dev](https://viorelay-android.pages.dev). Its [privacy policy](https://viorelay-android.pages.dev/privacy.html) and [support guide](https://viorelay-android.pages.dev/support.html) describe the current release status and installation steps.

## Package

- Android application ID: `com.lincstudio.viorelay`
- Distribution: direct APK download
- Release assets: official signed APKs only

Do not install development builds from this repository. A release will appear here only after the signing key and APK signature have been verified.
